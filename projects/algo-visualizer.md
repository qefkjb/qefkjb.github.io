一个把抽象算法过程做成可交互网页的小工具，目前覆盖了排序、图论、动态规划等常见专题。

## 为什么做这个

刷题的时候常常遇到这种情况：题解看懂了，但脑子里依然建立不起完整的「画面感」。把过程做成动画，看着数据一步步变化，能更快地理清转移过程。

## 功能特性

- 支持 30+ 种算法的动画演示
- 可以单步执行、拖动进度条、调速
- 一键生成分享链接，把当前状态传给同好

```text
打开网页 → 选择算法 → 输入数据 → 观察过程
```

## 技术栈

- 前端：原生 Canvas + 少量 React 组件
- 数据：算法用 TypeScript 实现，独立可测
- 部署：静态托管在 GitHub Pages

## 一些反思

第一版用 React 写了所有动画状态，结果包体积爆炸。后来把「算法状态」和「渲染」分离，算法只输出中间状态数组，渲染层用 Canvas 单独画，性能反而更好，调试也方便。
