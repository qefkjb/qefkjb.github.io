动态规划是算法竞赛中最核心的考点之一。本文整理几种常见的 DP 优化技巧，从思路到代码做一个系统的梳理。

## 1. 斜率优化

当 DP 转移方程形如：

$$dp[i] = \min_{j<i} \{ dp[j] + (a[i] - a[j])^2 \}$$

可以将每个决策点 $j$ 看作二维平面上的点，转移就变成了「求下凸壳上的最优切点」。用单调队列维护凸壳，转移降至 $O(1)$，整体复杂度 $O(n)$。

### 关键思路

1. 把转移方程改写为 $y = kx + b$ 的形式
2. 维护一个下凸壳（或上凸壳）的双端队列
3. 每次取出队首作为最优决策，新点从队尾插入并弹出不符合凸性的点

## 2. 决策单调性

若对于状态 $i$，最优决策点 $opt[i]$ 满足 $opt[i] \le opt[i+1]$，则称该 DP 具有**决策单调性**。

### 分治法

利用决策单调性，可以用分治在 $O(n \log n)$ 内完成转移：

```cpp
void solve(int l, int r, int optL, int optR) {
    if (l > r) return;
    int mid = (l + r) / 2, opt = optL;
    for (int k = optL; k <= min(mid - 1, optR); k++)
        if (calc(k, mid) < calc(opt, mid)) opt = k;
    dp[mid] = calc(opt, mid);
    solve(l, mid - 1, optL, opt);
    solve(mid + 1, r, opt, optR);
}
```

## 3. WQS 二分

当题目要求「恰好选 $k$ 个」时，可以先放宽限制求「无数量约束」的最优解，再通过二分一个额外代价 $\lambda$，调整选物品的数量直到恰好为 $k$。

> 适用条件：答案关于选取数量 $k$ 构成凸函数。

## 4. 数据结构优化

常见的有用线段树、树状数组优化转移：

- **区间最值转移**：线段树维护历史最大值
- **前缀最值转移**：树状数组维护前缀 max
- **二维偏序转移**：CDQ 分治或树套树

## 小结

| 优化方法 | 适用场景 | 复杂度 |
|----------|----------|--------|
| 斜率优化 | 转移含 $(a_i - a_j)^2$ 项 | $O(n)$ |
| 决策单调性 | 满足四边形不等式 | $O(n \log n)$ |
| WQS 二分 | 恰好选 $k$ 个 + 凸性 | $O(n \log V)$ |
| 数据结构 | 区间/前缀最优 | $O(n \log n)$ |

DP 优化的核心是**识别转移方程的结构**，找到可以剪枝或单调的性质。多做题、多总结，才能在赛场上快速反应。
