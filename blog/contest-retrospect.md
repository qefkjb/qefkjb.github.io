昨天打了一场 Codeforces Div.2，最终 AC 了 4 题，Rating +67，记录一下思路过程。

## A. 签到题

贪心题，排个序就过了。要注意读题，别被样例误导。

```cpp
sort(a.begin(), a.end());
long long ans = 0;
for (int i = 0; i < n; i++) ans += a[i] * (n - i);
```

## B. 构造题

要求构造一个长度为 $n$ 的排列，满足若干奇怪的条件。

这类题的关键是**找规律**：从小数据入手，手玩几个例子，往往能发现周期或对称的结构。

## C. DP 题

这才是这场比赛的精华。题意简化后是：给定数组，选若干不相邻的元素，使和最大。

经典的「打家劫舍」DP，$O(n)$ 转移：

$$dp[i] = \max(dp[i-1],\ dp[i-2] + a[i])$$

但本题还加了一个限制：不能同时选首尾。于是分两次 DP（强制不选首 / 强制不选尾）取 max 即可。

## D. 没做出的图论题

赛后看题解才发现是 **0-1 BFS**。每条边权值为 0 或 1，用双端队列代替优先队列即可 $O(V+E)$ 解决。

反思：对deque-based 0-1 BFS 不够熟练，下次要把模板再过一遍。

## 总结

- 签到题要快，别在 A、B 上浪费太多时间
- 构造题多手玩小数据
- 算法题识别模型最重要，DP / 图论的经典变体要烂熟于心
- 赛后补题是提升的关键，D 题明天补上
