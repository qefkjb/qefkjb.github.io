# LuckyPick 每日抽号

每日一次的抽数字游戏，灵感来自 RNGdle。从 0 到 1,000,000 抽取一个数字，根据质数、回文、连号、重复数字等模式解锁徽章并获得 EP。

## 玩法

- 每 UTC 日可抽取一次随机数
- 数字匹配徽章获得 EP，同家族徽章只计入最高
- 按 EP 百分位评定稀有度（垃圾 → 平凡 → 少见 → 稀有 → 史诗 → 异常 → 神话）
- 数据保存在浏览器本地
