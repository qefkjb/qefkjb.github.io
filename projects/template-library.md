一份从初学到现在不断打磨的算法模板库。每个模板都经过实战检验，注释清晰，可以直接拷进赛场。

## 设计原则

- **单一文件**：每个模板独立成文件，不互相依赖
- **零警告编译**：开启 `-Wall -Wextra` 也能干净通过
- **测试覆盖**：每个模板配 3 道以上对应题目作为回归测试
- **注释克制**：只写「为什么这样写」，不写显而易见的解释

## 模板分类

```text
templates/
├── dp/
│   ├── slope-trick.cpp        // 斜率优化
│   ├── decision-monotone.cpp  // 决策单调性
│   └── wqs-binary-search.cpp  // WQS 二分
├── ds/
│   ├── segment-tree.cpp       // 通用线段树
│   ├── lct.cpp                // Link-Cut Tree
│   └── persistent-seg.cpp     // 可持久化线段树
├── graph/
│   ├── dinic.cpp              // 最大流
│   └── scc.cpp                // 强连通分量
└── string/
    ├── sam.cpp                // 后缀自动机
    └── ac-automaton.cpp       // AC 自动机
```

## 一个小细节

模板里所有数组都开了 `const int MAXN`，看起来很朴素。但赛场上常常因为「局部数组开太大爆栈」或者「全局数组忘记开 long long」出意外。统一成宏定义后，赛场上只需要改一个数字就能切换规模，比每次手写舒服太多。

## 反思

最早写模板的时候追求「短」，结果每次用都要现场补细节，反而更慢。后来明白模板是给自己用的，**清晰比短更重要**，于是把每个关键步骤都展开成函数。代码长了 30%，但用起来的速度反而快了一倍。
