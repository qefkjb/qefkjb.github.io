# 林川个人作品网站

一个无需构建工具的静态作品集网站，可直接部署到 GitHub Pages。

## 本地查看

直接用浏览器打开 `index.html`。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库。
2. 上传本目录中的全部文件，保持 `assets` 目录结构不变。
3. 打开仓库的 `Settings > Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 选择 `main` 分支与 `/ (root)` 目录并保存。

GitHub 完成部署后，会显示网站访问地址。

## 替换内容

- 页面文案和链接：`index.html`
- 颜色、排版和响应式布局：`styles.css`
- 菜单、筛选和复制邮箱交互：`script.js`
- 图片素材：`assets/`

示例图片来自 [Unsplash](https://unsplash.com/)。正式发布前请替换姓名、邮箱、项目描述和社交链接。
